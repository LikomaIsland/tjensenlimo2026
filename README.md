## Deployment
Upload the entire folder to your web host. The site is static HTML/CSS/JS and does not require a server framework.

## Important
1. Replace the Unsplash image URLs with optimized local T. Jensen vehicle/brand photos before production. This will improve speed and branding.
2. Replace the mailto forms with the hosting provider's form handler, Formspree, Netlify Forms, PHP, or another server-side endpoint.
3. Verify the three phone numbers and add the correct official email address before launch.
4. Add the company's real address and Google Maps link when confirmed.
5. Add favicon and real social links if available.

## Design
Bright luxury palette, responsive navigation, accessible buttons/forms, semantic HTML5, lazy-loaded images, minimal JavaScript and no UI framework dependency.
